## Semantic Usage

- Action buttons and title tags use the ribbon trio (`left`, `mid`, `right`).
- Resource and status chips use badge/meter icons.
- Decorative labels and section headers use red flag sprites.
- Screen containers use frame/fill primitives for stronger depth.
- Store, rewards, rankings, and toasts use sprite icons instead of emoji.
- Decorative icons are rendered through CSS class-based sprite spans.
